# 🧠 AXIOM AGENT-SKILLS REGISTRY

**Orquestador de superpoderes para tus agentes de IA. Activa skills, ajusta parámetros, genera JSON listo para OpenAI/Claude.**

[![Demo](https://img.shields.io/badge/demo-live-00e5ff)](https://axiom-systemstech.github.io/axiom-agent-skills/)
[![TensorFlow](https://img.shields.io/badge/TensorFlow.js-IA-orange)](https://www.tensorflow.org/js)

## 🎯 ¿Qué hace?

- **15 skills predeterminadas** (X-Grabber, Web Scraper, Sentiment Analyzer, etc.)
- **Parámetros configurables** para cada skill
- **3 formatos de exportación** (OpenAI functions, Claude tools, Local)
- **Skill packs** (Modo Developer, Data Analyst, Social Media)
- **Recomendador con IA** (TensorFlow.js)
- **Templates guardables** y compartir por URL
